# nand-to-pwn
 
Every week I build one project that combines ideas from **CS50x** (high-level programming, C, algorithms, memory, web) and **nand2tetris** (how a computer is built from logic gates up), while practising security on the side with OverTheWire and CTFs.

## How this repo works
 
- **One folder per build.** Each is a finished project with its own README.
- **Concepts, not course solutions.** CS50x and nand2tetris both ask students not to publish their solutions, so problem sets and course chips live in a private repo. This repo contains only my own builds and the concepts they use.
- **Each build's README lists** what it does, the CS50x concepts used, the nand2tetris concepts used, and what I would improve.
